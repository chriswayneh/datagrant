# Security Policy

datagrant has no release yet. It is pre-alpha scaffolding and must not be used with real regulated data.

datagrant is designed to run locally as a CLI. Planned versions will connect only to the Postgres database you point it at, and will never log or store regulated data values.

To report a security issue, please use GitHub's private vulnerability reporting on this repository rather than a public issue. Do not include real PHI, PII, credentials, or keys in reports.
